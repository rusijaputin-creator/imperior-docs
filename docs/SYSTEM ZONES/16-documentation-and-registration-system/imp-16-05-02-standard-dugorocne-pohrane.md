# IMP-16-05-02 — Standard dugoročne pohrane

**Zona:** 16 — Dokumentacijski i registracijski sustav  
**Modul:** 16.5 — Arhiviranje i dugoročna pohrana  
**Status:** ODOBRENO

## 1. Predmet
Standard definira pravila dugoročne pohrane dokumentacije.

## 2. Zahtjevi
Dokumenti se čuvaju u stabilnom, čitljivom i provjerljivom formatu uz očuvanje metapodataka i povijesti verzija.

## 3. Sigurnosne kopije
Za kritičnu dokumentaciju mora postojati najmanje jedna odvojena sigurnosna kopija i provjerljiv postupak oporavka.

## 4. Rokovi čuvanja
Rok čuvanja određuje se prema vrsti, statusu i važnosti dokumenta.

## 5. Provjera
Periodično se provjerava čitljivost, integritet i dostupnost arhiviranih zapisa.
