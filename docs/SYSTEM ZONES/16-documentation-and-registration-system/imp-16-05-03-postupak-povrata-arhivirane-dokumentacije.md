# IMP-16-05-03 — Postupak povrata arhivirane dokumentacije

**Zona:** 16 — Dokumentacijski i registracijski sustav  
**Modul:** 16.5 — Arhiviranje i dugoročna pohrana  
**Status:** ODOBRENO

## 1. Svrha
Definira postupak pronalaska i povrata arhivirane dokumentacije.

## 2. Zahtjev
Povrat se pokreće evidentiranim zahtjevom s oznakom dokumenta i razlogom pristupa.

## 3. Provjera ovlasti
Prije povrata provjerava se pravo pristupa.

## 4. Povrat
Dokument se vraća u radni ili pregledni režim bez izmjene arhivske izvornosti.

## 5. Evidencija
Svaki povrat mora ostaviti zapis o korisniku, vremenu, svrsi i rezultatu.
