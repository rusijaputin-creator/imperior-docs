# IMP-16-09-01 — Standard međuzonskih dokumentacijskih veza

**Zona:** 16  
**Modul:** 16.9 — Povezivanje dokumentacije između zona  
**Status:** ODOBRENO

## 1. Svrha
Definira standard povezivanja dokumenata koji pripadaju različitim zonama.

## 2. Veze
Veza mora navesti izvorni dokument, povezani dokument i vrstu odnosa.

## 3. Referenciranje
Reference moraju koristiti službene oznake dokumenata.

## 4. Promjene
Kod promjene oznake ili statusa provjeravaju se sve povezane reference.

## 5. Kontrola
Zona 16 održava pravila međuzonske dokumentacijske interoperabilnosti.
