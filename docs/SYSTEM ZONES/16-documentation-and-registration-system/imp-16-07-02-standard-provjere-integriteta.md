# IMP-16-07-02 — Standard provjere integriteta

**Zona:** 16  
**Modul:** 16.7 — Autentikacija i integritet dokumentacije  
**Status:** ODOBRENO

## 1. Predmet
Standard definira kontrolu cjelovitosti dokumenta i njegovih metapodataka.

## 2. Provjera
Provjeravaju se sadržaj, verzija, status, naziv, poveznice i evidencija izmjena.

## 3. Odstupanja
Svako neslaganje označava se kao dokumentacijsko odstupanje.

## 4. Ispravak
Ispravci se provode novom kontroliranom verzijom ili formalnim zapisom.

## 5. Rezultat
Dokument se nakon provjere označava kao potvrđen ili zahtijeva korektivnu obradu.
