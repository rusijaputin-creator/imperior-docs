# IMP-16-08-02 — Standard dokumentacijskih ovlasti

**Zona:** 16  
**Modul:** 16.8 — Pristup, ovlasti i sljedivost  
**Status:** ODOBRENO

## 1. Uloge
Standard razlikuje ovlasti pregleda, uređivanja, odobravanja, arhiviranja i administriranja.

## 2. Dodjela
Ovlasti moraju biti izričito dodijeljene i povezane s ulogom.

## 3. Sukob ovlasti
Kritične funkcije pregleda i odobravanja, gdje je primjenjivo, razdvajaju se.

## 4. Promjene
Svaka promjena ovlasti mora biti evidentirana.

## 5. Kontrola
Periodično se provjerava jesu li dodijeljene ovlasti i dalje opravdane.
