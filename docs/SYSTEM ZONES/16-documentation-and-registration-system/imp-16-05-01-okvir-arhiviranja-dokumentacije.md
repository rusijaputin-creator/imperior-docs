# IMP-16-05-01 — Okvir arhiviranja dokumentacije

**Zona:** 16 — Dokumentacijski i registracijski sustav  
**Modul:** 16.5 — Arhiviranje i dugoročna pohrana  
**Status:** ODOBRENO

## 1. Svrha
Ovim dokumentom uspostavlja se jedinstveni okvir za arhiviranje službene dokumentacije projekta IMPERIOR.

## 2. Načela
- cjelovitost dokumentacije
- dostupnost ovlaštenim korisnicima
- zaštita izvornosti
- sljedivost promjena
- dugoročna očuvanost

## 3. Obuhvat
Okvir se primjenjuje na aktivnu, završenu, povučenu i povijesnu dokumentaciju svih zona sustava.

## 4. Odgovornosti
Za provedbu arhiviranja odgovorna je dokumentacijska funkcija Zone 16 u koordinaciji s vlasnicima pojedinih dokumenata.

## 5. Kontrola
Svaki arhivirani dokument mora imati identifikacijsku oznaku, verziju, status, datum arhiviranja i evidentiranu lokaciju pohrane.
