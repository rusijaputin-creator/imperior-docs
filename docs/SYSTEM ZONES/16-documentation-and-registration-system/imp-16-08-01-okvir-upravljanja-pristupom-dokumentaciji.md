# IMP-16-08-01 — Okvir upravljanja pristupom dokumentaciji

**Zona:** 16  
**Modul:** 16.8 — Pristup, ovlasti i sljedivost  
**Status:** ODOBRENO

## 1. Svrha
Definira načela pristupa dokumentaciji i kontrole ovlasti.

## 2. Načelo najmanjih ovlasti
Korisnik dobiva samo pristup potreban za svoju ulogu.

## 3. Razredi pristupa
Dokumenti mogu biti javni, interni, ograničeni ili posebno zaštićeni.

## 4. Evidentiranje
Pristup važnoj dokumentaciji mora biti sljediv.

## 5. Ukidanje prava
Ovlasti se povlače kada više ne postoji opravdana potreba.
