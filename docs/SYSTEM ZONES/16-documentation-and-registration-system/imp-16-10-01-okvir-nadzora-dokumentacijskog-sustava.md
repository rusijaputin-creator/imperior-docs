# IMP-16-10-01 — Okvir nadzora dokumentacijskog sustava

**Zona:** 16  
**Modul:** 16.10 — Nadzor dokumentacijskog sustava  
**Status:** ODOBRENO

## 1. Svrha
Uspostavlja kontinuirani nadzor rada dokumentacijskog i registracijskog sustava.

## 2. Obuhvat
Nadzor obuhvaća cjelovitost, ažurnost, dostupnost, duplikate, neispravne reference, statuse i revizijsku sljedivost.

## 3. Kontrole
Provode se periodične i ciljane provjere.

## 4. Odstupanja
Nalazi se klasificiraju i upućuju na korektivnu obradu.

## 5. Izvještavanje
Rezultati se evidentiraju kroz službene izvještaje Zone 16.
