# IMP-16-06-01 — Okvir registara i službenih evidencija

**Zona:** 16  
**Modul:** 16.6 — Registri i službene evidencije  
**Status:** ODOBRENO

## 1. Svrha
Uspostavlja sustav registara i službenih evidencija projekta IMPERIOR.

## 2. Vrste evidencija
Registri mogu sadržavati dokumente, odluke, statuse, ovlasti, revizije, događaje i druge službene zapise.

## 3. Jedinstvenost
Svaka evidencija mora imati jasno definiran naziv, vlasnika, strukturu i pravilo održavanja.

## 4. Točnost
Podaci u registrima moraju biti provjerljivi, ažurni i sljedivi.

## 5. Nadzor
Zona 16 nadzire usklađenost registara s glavnim dokumentacijskim pravilima.
