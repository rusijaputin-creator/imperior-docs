# IMP-16-09-03 — Postupak provjere međuzonskih referenci

**Zona:** 16  
**Modul:** 16.9 — Povezivanje dokumentacije između zona  
**Status:** ODOBRENO

## 1. Pokretanje
Provjera se provodi pri izmjeni strukture, dokumenta ili službene oznake.

## 2. Koraci
Identificiraju se reference, provjerava cilj, status i valjanost veze.

## 3. Neispravne veze
Nevažeće ili zastarjele reference evidentiraju se i ispravljaju.

## 4. Završna potvrda
Promjena se smatra završenom kada su povezane reference ponovno provjerene.
