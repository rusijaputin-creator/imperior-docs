# IMP-16-09-02 — Matrica povezanosti dokumentacije između zona

**Zona:** 16  
**Modul:** 16.9 — Povezivanje dokumentacije između zona  
**Status:** ODOBRENO

## 1. Funkcija
Matrica prikazuje ključne odnose dokumenata između zona.

## 2. Polja
Izvorna zona, izvorni dokument, povezana zona, povezani dokument, vrsta veze i status provjere.

## 3. Primjena
Koristi se za kontrolu ovisnosti, promjena i utjecaja između zona.

## 4. Održavanje
Ažurira se kod svake značajne promjene strukture ili oznaka dokumenata.
