# IMP-16-06-03 — Glavni registar službenih evidencija

**Zona:** 16  
**Modul:** 16.6 — Registri i službene evidencije  
**Status:** ODOBRENO

## 1. Funkcija
Ovaj dokument definira glavni indeks svih službenih evidencija.

## 2. Sadržaj registra
Registar vodi naziv evidencije, oznaku, odgovornu zonu, status, lokaciju i datum zadnjeg ažuriranja.

## 3. Povezivanje
Svaka službena evidencija mora biti povezana s relevantnim dokumentima i modulima.

## 4. Kontrola duplikata
Nije dopušteno paralelno vođenje dviju kanonskih evidencija iste svrhe.

## 5. Održavanje
Registar se ažurira pri svakoj relevantnoj promjeni.
