# IMP-16-06-02 — Standard vođenja registara

**Zona:** 16  
**Modul:** 16.6 — Registri i službene evidencije  
**Status:** ODOBRENO

## 1. Obvezna polja
Svaki službeni zapis mora sadržavati identifikator, naziv, status, datum, izvor i odgovornu funkciju.

## 2. Izmjene
Promjene se provode kontrolirano i ne smiju izbrisati povijest prethodnih zapisa.

## 3. Statusi
Statusi zapisa moraju biti standardizirani i jednoznačni.

## 4. Revizijski trag
Sve važne promjene moraju biti evidentirane.

## 5. Dostupnost
Pristup registrima uređuje se prema ovlastima i ulozi korisnika.
