# IMP-16-08-03 — Registar pristupa i sljedivosti

**Zona:** 16  
**Modul:** 16.8 — Pristup, ovlasti i sljedivost  
**Status:** ODOBRENO

## 1. Svrha
Vodi službeni zapis pristupa i važnih radnji nad dokumentacijom.

## 2. Evidentira se
korisnik ili funkcija, dokument, vrsta radnje, vrijeme i rezultat.

## 3. Sljedivost
Zapis mora omogućiti rekonstrukciju ključnih dokumentacijskih radnji.

## 4. Zaštita
Evidencija pristupa ne smije se mijenjati bez kontroliranog administrativnog postupka.
