# IMP-16-07-03 — Evidencija autentikacije i provjera

**Zona:** 16  
**Modul:** 16.7 — Autentikacija i integritet dokumentacije  
**Status:** ODOBRENO

## 1. Svrha
Vodi službenu evidenciju provjera autentičnosti i integriteta.

## 2. Evidentira se
- oznaka dokumenta
- verzija
- datum provjere
- rezultat
- odgovorna osoba ili funkcija
- utvrđena odstupanja

## 3. Povijest
Prethodni rezultati ne brišu se nego ostaju dio revizijskog traga.

## 4. Povezanost
Evidencija se povezuje s registrom dokumenata i zapisima o izmjenama.
