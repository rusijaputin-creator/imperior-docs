# IMP-16-07-01 — Standard autentikacije dokumentacije

**Zona:** 16  
**Modul:** 16.7 — Autentikacija i integritet dokumentacije  
**Status:** ODOBRENO

## 1. Svrha
Utvrđuje kako se potvrđuje vjerodostojnost službene dokumentacije.

## 2. Identitet dokumenta
Autentični dokument mora imati jedinstvenu oznaku, naslov, verziju, status i izvor.

## 3. Potvrda
Autentikacija se može temeljiti na kontroliranom repozitoriju, revizijskoj povijesti i ovlaštenom odobrenju.

## 4. Neovlaštene kopije
Kopija bez provjerljivog izvora ne smatra se kanonskom verzijom.

## 5. Evidencija
Rezultati provjere autentikacije moraju biti sljedivi.
