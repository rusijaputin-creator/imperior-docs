SVRHA

Zona 02 predstavlja središnju stratešku razinu sustava
IMPERIOR.

Upravlja dugoročnim planiranjem, strateškim ciljevima,
analitikom, mjerenjem rezultata, upravljanjem rizicima,
kriznim upravljanjem i razvojnim programima.

FUNKCIJA ZONE

Zona 02 povezuje temeljne ciljeve IMPERIOR-a
s njihovom konkretnom provedbom.

Strateške odluke pretvaraju se u planove, programe,
mjerljive pokazatelje i operativne prioritete.

Rezultati se zatim analiziraju i koriste za
kontinuirano prilagođavanje sustava.
