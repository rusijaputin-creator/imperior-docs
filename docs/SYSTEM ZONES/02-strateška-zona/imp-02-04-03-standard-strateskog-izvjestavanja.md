# STANDARD STRATEŠKOG IZVJEŠTAVANJA

Kod: IMP-02-04-03  
Status: ACTIVE  
Verzija: 1.0  
Zona: 02 — STRATEŠKA ZONA  
Cjelina: 02.4 — ANALITIKA

## 1. SVRHA

Dokument definira jedinstveni standard izvještavanja o stanju, provedbi i rezultatima strateških aktivnosti.

## 2. TEMELJNE ODREDBE

- sažetak stanja
- ključni pokazatelji
- odstupanja
- rizici
- provedene mjere
- preporuke
- status sljedećih aktivnosti

## 3. OPERATIVNI MODEL

**STANJE → PODACI → REZULTATI → ODSTUPANJA → RIZICI → PREPORUKE**

## 4. ODGOVORNOST I KONTROLA

Za svaku značajnu aktivnost moraju biti utvrđeni odgovorna cjelina, rok, status, način izvještavanja i kontrolna točka.

Dokumentacija mora omogućiti sljedivost odluke, provedbe, rezultata i naknadne revizije.
