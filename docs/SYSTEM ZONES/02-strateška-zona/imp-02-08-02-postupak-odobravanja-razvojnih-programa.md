## 1. SVRHA

Dokument definira postupak kojim razvojni prijedlog prelazi iz koncepta u odobreni program.

## 2. TEMELJNE ODREDBE

- opis potrebe
- analiza koristi i troškova
- procjena resursa
- procjena rizika
- pravna i organizacijska provjera
- odobrenje odgovorne razine

## 3. OPERATIVNI MODEL

**PRIJEDLOG → ANALIZA → PROVJERA → ODLUKA → REGISTRACIJA → POKRETANJE**

## 4. ODGOVORNOST I KONTROLA

Za svaku značajnu aktivnost moraju biti utvrđeni odgovorna cjelina, rok, status, način izvještavanja i kontrolna točka.

Dokumentacija mora omogućiti sljedivost odluke, provedbe, rezultata i naknadne revizije.
