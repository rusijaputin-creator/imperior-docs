## 1. SVRHA

Dokument definira način praćenja provedbe i završne evaluacije razvojnih programa.

## 2. TEMELJNE ODREDBE

- praćenje faza
- praćenje rokova
- KPI pokazatelji
- praćenje troškova
- praćenje rizika
- završna evaluacija
- preporuke za nastavak ili zatvaranje

## 3. OPERATIVNI MODEL

**PLAN → PROVEDBA → MJERENJE → ODSTUPANJE → KOREKCIJA → EVALUACIJA → ODLUKA**

## 4. ODGOVORNOST I KONTROLA

Za svaku značajnu aktivnost moraju biti utvrđeni odgovorna cjelina, rok, status, način izvještavanja i kontrolna točka.

Dokumentacija mora omogućiti sljedivost odluke, provedbe, rezultata i naknadne revizije.
